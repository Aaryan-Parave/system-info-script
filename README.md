# System Info Script

A Simple Bash script that prints basic system information to the Terminal

## What it Shows 
- Current Date and Time 
- Shows User name and how long the system is been running 
- General System Information 
- Disk Usage 
- Memory Usage
- Top 5 Running Processes in the Memory
- Displays the Current CPU usage 


## Requirements
- Linux (tested on Ubuntu)
- bash shell

## Usage
```bash
chmod +x system_info.sh
./system_info.sh
```
